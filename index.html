    Conexões & seus dados

    Google Drive

    A página atualiza o arquivo .md escolhido, preservando o link. Funciona enquanto estiver aberta, online e autorizada. A autorização expira e precisa ser renovada com um clique.

    Configuração inicial do Google

    Crie um projeto Google Cloud, habilite Drive API e Google Picker API e configure um cliente OAuth do tipo Web. Use esta origem autorizada: . Cadastre sua conta como usuário de teste se o app estiver em testes. Não é necessária chave da OpenAI nem segredo OAuth.

    A chave do Picker deve permitir seu domínio e https://docs.google.com/*, restrita às APIs Picker e Drive. Veja o passo a passo completo no README.

    Nenhum arquivo autorizado.

    Selecione o arquivo pelo seletor Google; digitar seu ID não concede acesso. A primeira substituição pede confirmação. O .md não é um backup completo das avaliações.

    Biblioteca & backup

    Seus dados são salvos neste navegador. Exportar JSON preserva jogos, avaliações, comentários e previsões; o Markdown contém somente a fila para jogar. Importe o JSON em outro dispositivo para continuar.

    Ao importar, você confirma a substituição dos dados locais. Um backup anterior é baixado automaticamente. Limpar os dados do navegador sem backup pode apagar suas avaliações.
