    Consultando GitHub…

    As cópias são diferentes.

    Nenhuma foi sobrescrita. Baixe seu backup antes de decidir. As opções abaixo substituem uma cópia inteira; não fazem mesclagem.

    Como criar o token com acesso restrito
    1. Abra GitHub → Fine-grained tokens.
    2. Escolha uma validade curta e o proprietário joaopkato.
    3. Em Repository access, escolha Only select repositories → proximo-jogo.
    4. Em Repository permissions, habilite somente Contents → Read and write. Metadata de leitura é automático.
    5. Gere o token e cole no campo acima. Não o envie ao ChatGPT nem o coloque no JSON.

    O token permite editar conteúdo de todo esse repositório, não apenas o JSON. Proteja-o como uma senha. Ele é enviado somente à API do GitHub e não é salvo em localStorage, sessionStorage ou backups. Recarregar/fechar exige informar novamente. “Esquecer” limpa a memória; a revogação é feita nas configurações do GitHub.

    Uma cópia de segurança

    O JSON preserva toda a biblioteca; o Markdown contém somente a fila para jogar. A importação abaixo muda apenas sua cópia local até você salvar no GitHub.

    Conteúdo publicado pode permanecer no histórico e em cópias de terceiros. Não registre segredos nas notas ou comentários.
